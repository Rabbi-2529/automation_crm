How webhooks work

  • Each timeline event you pick is POSTed as JSON, with the contact / deal / company in the same shape as the REST API.
  • Every request is signed: X-ThingBD-Signature: t=…,v1=… is HMAC-SHA256 of t + "." + body with the endpoint's secret.
  • Reply with any 2xx. Failures are retried after 1 min, 5 min, 30 min, 2 h and 6 h; an endpoint that fails 50 times in a row is switched off.
  • Need logic first? Use the Call a webhook step inside an automation instead.
