How it works

  1. The trigger is the event that starts it.
  2. Conditions decide which contacts or deals go in.
  3. Steps run in order. A Wait pauses the run; Continue only if… can stop it.

Each contact/deal goes through once unless you allow it to run again. Workflows can trigger each other up to 3 levels deep.
